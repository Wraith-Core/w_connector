# w_connector (v2)

يربط سيرفر FiveM أو RedM بلوحة Wraith، وينفذ أوامر الإدارة ويعرض حالة اللاعبين.
تتوفر لوحة w_admin الأصلية داخل الموصل بالأمر `/wadmin` أو Page Up، وقائمتها السريعة بـF10 أو `/wquickadmin` في RedM وFiveM.
تظهر الصفحات والأفعال حسب صلاحيات حساب الموقع. إدارة الرتب المفوّضة متاحة من داخل اللعبة لمن لديه صلاحية إدارة الرتب.
توجد أيضًا أوامر البلاغات بحسب الإعدادات. يتطلب المورد `oxmysql` وإطارًا مدعومًا.

> This is v2, shipped under the name `w_connector` so the Wraith systems (which answer only that
> name) work unchanged. It replaces v1, whose source is kept in `game/w_connector_v1` for rollback:
> put the v1 folder back and start it. Design: `docs/admin-platform/03-connector-v2.md`.

## Install

1. Requirements: `oxmysql`, and one supported framework.
2. Put `w_connector` in `resources/`.
3. On your panel, create the connector token, then add to `server.cfg`:

```cfg
set wraith_token "wc2.k…"
ensure w_connector
add_ace resource.w_connector command allow
```

Start it **after** your framework and inventory.

## Supported

| Framework | Inventory |
|---|---|
| Wraith Core (`w_core`) | Wraith (`w_inventory`) |
| VORP (`vorp_core`) | `vorp_inventory`, `ox_inventory` (RedM) |
| RSG (`rsg-core`) | `rsg-inventory` |
| ESX (`es_extended`) | `ox_inventory`, or ESX's own |
| QBCore (`qb-core`) | `qb-inventory` |
| Qbox (`qbx_core`) | `ox_inventory` |

Detected automatically. To force one: `set wraith_framework "vorp"` / `set wraith_inventory "ox_inventory"`.

## Security

- The token belongs to this one server and this one product. Keep `server.cfg` private; if it leaks,
  create a new token on the panel — the old one stops working.
- Every request is signed (HMAC-SHA256, timestamp and one-time nonce) and goes out over HTTPS. The
  server opens no port.
- The token cannot change who has access to your panel.

## 2.2.0 — 2026-11-01

- لوحة الإدارة داخل اللعبة لا تحتاج w_admin بعد الآن: الشخصيات (البحث، الإيقاف، تغيير الرقم، نقل الرقم، الحذف، المال والأغراض والوظيفة للمتصل وغير المتصل)، وإعدادات السكربتات والهود والاحتياجات، وأخبار قائمة الإيقاف، ومركز السكربتات، وفتح الملابس وركوب الحصان القريب؛ كلها تعمل من الموصل نفسه بنفس الصلاحيات والقيود (سبب المال وحده الأعلى، القفل ضد الضغط المكرر).
- أوامر مركز السكربتات تُبنى في السيرفر من قائمة ثابتة، وتعمل بصلاحيات الإداري نفسه؛ لا يُقبل نص أمر حر من الصفحة.
- الربط مع أداة التشغيل الجديدة (بديل txAdmin): نبض كل 3 ثوانٍ يكشف تعليق السيرفر، وقبل أي إيقاف أو إعادة تشغيل تصل السكربتات نفس إشارة الحفظ التي كانت ترسلها txAdmin، ويُمنع الدخول، ويخرج اللاعبون برسالة عربية. تحذيرات إعادة التشغيل المجدولة تظهر كإعلان أعلى الشاشة.
- أمر `/closeserver` و`/openserver` يعملان من جديد مع الموصل، ويبقى السيرفر مغلقًا حتى لو تعذّر الوصول للموقع (يدخل من لديه صلاحية `wraithadmin.join` فقط).
- رسائل رفض الدخول بالعربي: الحظر مع سببه ورقمه ووقت انتهائه، السيرفر مغلق، القائمة المسموحة.
- البحث الفارغ في صفحة الشخصيات يعرض آخر 60 شخصية كما كان.
- تجربة اللعبة المطلوبة: أوقف w_admin على Studio ثم افتح اللوحة (Page Up وF10)، وجرّب: البحث عن شخصية وإيقافها ورفع الإيقاف، تعديل جوع لاعب، حفظ إعداد في الهود، إضافة خبر، فتح لوحة سكربت من المركز، فتح الملابس للاعب، `/closeserver` ثم محاولة دخول بحساب عادي ثم `/openserver`.

## 2.1.0 — 2026-11-01

- لوحة w_admin وقائمة F10 داخل الموصل، بنفس الواجهة والبحث السريع والشرح بالعربي والإنجليزي؛ لا تحتاج إلى تثبيت w_admin لفتح اللوحة وأدواتها العامة.
- إدارة اللاعبين والتنقل والطيران والحماية والاستدعاء المؤقت والمركبات والكيانات والبلاغات والحظر والسجلات، بحسب صلاحيات الموقع والإضافات المشغّلة.
- الرتب داخل اللوحة مرتبطة بحساب ديسكورد وصلاحيات الموقع. يستطيع المفوّض إدارة ما سُمح له فقط، ولا تتحول الرتبة إلى ماستر للفريمورك.
- يتعرف الموصل على WCore وVORP وRSG وESX وQBCore وQbox. الوظائف والحقيبة والمال تُنفّذ من نظام السيرفر؛ لا يفترض وجود وظائف أو حسابات غير متاحة فيه.
- الخرائط المخصصة وواجهة الجوع والأخبار ومحررات إعدادات سكربتات Wraith تظهر عند توفر إضافاتها المتوافقة وصلاحياتها. محررات Wraith الأصلية تحتاج إلى جسر w_admin المحدّث وصلاحياته أيضًا؛ وجود لوحة الموصل لا يوفّر تلك السكربتات تلقائيًا.
- إذا كان w_admin موجودًا، يُحوّل اختصاراته للوحة الموحدة بعد تحديث الجسر، حتى لا تفتح لوحتان فوق بعضهما.
- الأدوات غير المدعومة أو غير المسموحة تُعطّل مع توضيح السبب. إزالة الصلاحية أو انتهاء الربط توقف الأوضاع الإدارية وتحرر التحكم.
- الحظر يحفظ هوية اللاعب الأصلية؛ تبدل رقم الجلسة لا يوجّه الإجراء للاعب آخر. إذا حُفظ الحظر وتعذر فصل الاتصال تظهر رسالة توضح ذلك.
- الطيران والمراقبة يستخدمان تصاريح حماية قصيرة للأوضاع المفعّلة فقط. لا يمنح الموصل إعفاءً عامًا من الحماية.
- ملفات مصدر الواجهة وترخيصها مرفقة مع الحزمة داخل `LICENSES`.

تجربة اللعبة المطلوبة: افتح F10 وPage Up و`/wadmin`، جرّب حسابًا محدود الصلاحيات، واسحب الصلاحية وهو متصل. افحص التنقل والمراقبة وإغلاق اللوحة واستدعاء نموذج وحذف كيان فارغ، ثم أعد التجربة على كل فريمورك مستهدف قبل اعتماد توافقه الفعلي.

## 2.0.2 — 2026-11-01

- صلاحيات السكربتات المختارة من دور الموقع تسري داخل اللعبة، حسب هوية ديسكورد التي يبلغها السيرفر.
- تظهر الصلاحيات بالعربي حسب السكربت المشغّل؛ لا يمنح دور الموقع صلاحيات عامة أو رتبة ماستر تلقائيًا.
- تُجدّد المنح كل 15 ثانية، وتنتهي خلال 45 ثانية إذا تعذر التحقق. إزالة الدور أو خروج اللاعب تسحب منح الموصل فقط.
- لا تحفظ المنح كرتب دائمة. يُحفظ سجل تنظيف بأسماء المنح التي أنشأها الموصل لإزالتها عند عودة تشغيله، ولا يعيد منح صلاحيات من هذا السجل.
- إذا رفض السيرفر تنفيذ السحب، يحتفظ الموصل بسجل التنظيف ويعيد المحاولة ويظهر تنبيهًا في الكونسول؛ لا يتجاوز إعدادات صلاحيات السيرفر.
- يلزم سطر `add_ace resource.w_connector command allow` لتطبيق المنح المؤقتة وسحبها. تبقى الرتب اليدوية مستقلة.
- تجربة اللعبة المطلوبة: حساب لديه صلاحية المزرعة فقط، إزالة الصلاحية وهو متصل، ثم تجربة انقطاع الربط وإعادة الدخول.
